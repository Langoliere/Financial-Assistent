# API rules

- Use FastAPI.
- Use Pydantic v2 for request and response schemas.
- Implement:
  - GET /health
  - GET /v1/model-info
  - POST /v1/predict/direction
- Use API version prefix /v1.
- Return 422 for invalid input.
- Return 503 if the model is not loaded.
- Do not expose internal file paths or stack traces in API responses.
- Use structured logging.
- Do not log raw API keys, secrets, or full request payloads.
- The prediction endpoint accepts at least 21 daily OHLCV observations.
- The model uses a lookback window of 20 observations.
